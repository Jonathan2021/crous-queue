Accepted for local Q06 scope, 2026-10-08.

The existing 17 backend/6 browser gates pass, but a disposable release/restart replay shows stale CSS from the constant cache-first shell. The service worker now uses a content-derived revision and fetches static assets online before falling back to shell caches. Activation cleans only this app's shell caches; APIs/navigation data and writes remain uncached. A real Chromium restart/upgrade/offline replay verifies the behavior.

Disposable logger rehearsal also demonstrates environment mixing and an all-national returning-device count in a two-site pilot. New schema-v2 aggregate records bind environment, synthetic/real mode and credential-free storage identity; scheduled records additionally bind a reviewed five-day plan and slot. The append writer rejects mismatches, duplicates/corrections and legacy records without replacing bytes; legacy evidence remains available for manual review. Existing national admin metrics stay national, while pilot metrics explicitly scope to Cuvier/Châtelet.

Twenty paired slots define 40 planned venue checks. Missing records stay missing; unknown is a performed check without recent estimates. Summary reports fresh/actual and fresh/planned numerators/denominators, state counts and nullable separate friction diagnostics. Raw reports and device hashes never enter measurement logs. Counts of repeated devices are proxies, not unique people, adoption or predictions. The five-day rehearsal and blank preparation need no production data or actual visits.

Revisit only if voluntary approved physical evidence reveals another measurement gap. Real private access/intake, PostgreSQL/public hosting, provider costs and queue eligibility remain separate gates. No new runtime dependency on Foundry or another venture is introduced.
